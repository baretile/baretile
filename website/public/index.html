baretile

baretile is a compiler and runtime for Tenstorrent Blackhole. It's written in Python, including the driver that talks to the chip over PCIe.

We want to make these cards run faster while keeping the software small enough for one person to understand and change. We write our own firmware for the workers, and the core Python code uses only the standard library. The compiler generates Tensix instructions directly. There's no dependency on tt-metal, tt-umd or LLK. We still use Tenstorrent's board firmware for ARC and Ethernet.

For now, we are developing on the ttsim simulator. We haven't run baretile on a card yet, so we don't know exactly how fast it is.

Using it

You can write tensor operations in Python:

from baretile import pci
from baretile.chip import Chip
from baretile.runtime import Runtime
from baretile.tensor import Tensor

rt = Runtime(Chip(pci.open_device()))
x = Tensor.of(rt, [[1.0, 2.0], [3.0, 4.0]])
w = Tensor.of(rt, [[2.0, 0.0], [0.0, 3.0]])

print((x @ w).relu().tolist())
# [[2.0, 6.0], [6.0, 12.0]]

Here, the compiler puts the matrix multiply and ReLU in one kernel. Calling tolist() runs the computation and copies the answer back to Python.

There are also examples that generate text with GPT-2 and Llama, a small GPT that you can train, and an HTTP server that accepts OpenAI-compatible requests. We check the models against NumPy and the training example against PyTorch.

Getting started

You don't even need a card. You'll need Python 3, clang with a RISC-V target, lld, and a Blackhole build of ttsim.

Follow the setup instructions, then run this from the baretile checkout:

export TTSIM=/absolute/path/to/ttsim/src/_out/release_bh/libttsim.so
python3 -m baretile.hello

This runs a Fibonacci program on the simulated workers and reads back their answers. Keep TTSIM set for the tensor example too. Without TTSIM, baretile tries to open a real card.
