baretile

baretile is a compiler and runtime for Tenstorrent Blackhole. It's written in Python, including the driver that talks to the chip over PCIe.

You write tensor operations, and the compiler turns them into Tensix instructions. The code in baretile/ uses only the Python standard library. The driver runs in userspace and loads our firmware onto the workers. We use Tenstorrent's board firmware for ARC and Ethernet, with no dependency on tt-metal, tt-umd or LLK.

We develop on Tenstorrent's ttsim simulator. We haven't tested baretile on a card yet. Simulator timings don't predict card performance.

Using it

After setting up ttsim, install baretile and run it from Python:

from baretile import pci
from baretile.chip import Chip
from baretile.runtime import Runtime
from baretile.tensor import Tensor

rt = Runtime(Chip(pci.open_device()))
x = Tensor.of(rt, [[1.0, 2.0], [3.0, 4.0]])
w = Tensor.of(rt, [[2.0, 0.0], [0.0, 3.0]])

print((x @ w).relu().tolist())
# [[2.0, 6.0], [6.0, 12.0]]

The compiler combines the matrix multiplication and ReLU in one kernel. Calling tolist() runs the computation and copies the answer back to Python.

There are also examples that generate text with GPT-2 and Llama, a small GPT that you can train, and an HTTP server that accepts OpenAI-compatible requests. We check the models against NumPy and the training example against PyTorch.

Getting started

Install baretile in a Python 3.12 or later virtual environment on Linux. On Debian and Ubuntu, install python3-venv, clang with a RISC-V target, lld, curl and git. Then install the package, download the simulator and check the setup:

python3 -m venv baretile-env
. baretile-env/bin/activate
python3 -m pip install baretile
python3 -m baretile.chip ttsim
python3 -m baretile.chip check

In fish, activate with . baretile-env/bin/activate.fish. The simulator download uses the tested ttsim v1.11.5 release. If setup reports a missing dependency, chip check explains how to fix it.

You can run the examples on the simulator using the setup steps above. baretile is installed as a package, so you do not need a checkout to run its commands.

To run the Fibonacci example and inspect the chip:

python3 -m baretile.chip
python3 -m baretile.hello

On ttsim, baretile.hello reports that 119 of 120 Tensix workers computed fib(30) = 832040, while one tile dispatched the work.

For a different simulator build, such as ttsim-chaos, set TTSIM=/absolute/path/to/libttsim.so. That library is tried before a physical card and before the downloaded release. Without TTSIM, baretile opens a real card if one is present; card access needs root and takes the card away from its kernel driver.

For model inference or the HTTP server, install baretile[models] to add NumPy. The models include GPT-2 and Llama, and the server accepts OpenAI-compatible requests.

Learning it

The ramps teach baretile from the top down. Each one is a script that explains its steps and checks their results:

python3 ramps/1_tensors.py   # tensor operations, fusion, formats, gradients and jit
python3 ramps/2_runtime.py   # C kernels on the workers, DRAM and the NoC
python3 ramps/3_tensix.py    # unpack, math and pack programs written by hand

The documentation explains the runtime, the compiler, the models and the hardware.
